💾 Резервное копирование

Все данные «Орлова фитнес» автоматически сохраняются в памяти вашего iPhone. Скачивайте файл копии раз в неделю, чтобы не потерять базу при очистке Safari.

  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх внизу экрана).
  3. Выберите пункт «На экран „Домой“».
